# CyberGuard AI Backend

FastAPI & Machine Learning Backend for CyberGuard AI Enterprise Platform.

## Features
- Async Ingestion with Redis Queue
- Real-time Rule-based Detection & Threat Intelligence
- Machine Learning Ensemble Anomaly Detection (Isolation Forest, PyTorch Autoencoder, DBSCAN)
- TimescaleDB / PostgreSQL partitioned event storage
- Real-time WebSockets & SOAR Response Playbook Engine
